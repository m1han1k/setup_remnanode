У вас возникла проблема:
  ❌ sudo systemctl start docker
  Job for docker.service failed...

Это часто происходит при неполной установке Docker.

═══════════════════════════════════════════════════════════════════════════════
  ВАРИАНТ 1️⃣ : АВТОМАТИЧЕСКОЕ РЕШЕНИЕ (самое быстрое - 2 минуты)
═══════════════════════════════════════════════════════════════════════════════

Скачайте и запустите скрипт восстановления:

  sudo bash docker-fix.sh

Скрипт автоматически:
  ✓ Остановит Docker
  ✓ Удалит старую установку полностью
  ✓ Переустановит Docker из официального репозитория
  ✓ Проверит, что всё работает

Готово! Можете сразу запускать:
  ./setup-remnanode.sh

═══════════════════════════════════════════════════════════════════════════════
  ВАРИАНТ 2️⃣ : РУЧНОЕ РЕШЕНИЕ (если хотите видеть что происходит)
═══════════════════════════════════════════════════════════════════════════════

Скопируйте и выполните эти команды по одной:

  # 1. Остановить Docker
  sudo systemctl stop docker || true

  # 2. Удалить старую версию полностью
  sudo apt remove -y docker.io docker-ce docker-ce-cli containerd.io
  sudo apt autoremove -y
  sudo rm -rf /var/lib/docker /var/lib/containerd
  sudo rm -f /etc/apt/sources.list.d/docker.list

  # 3. Обновить список пакетов
  sudo apt update

  # 4. Установить всё с нуля (из официального репозитория)
  sudo apt install -y curl wget git nano jq ca-certificates gnupg lsb-release

  sudo mkdir -p /etc/apt/keyrings
  
  curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
    sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
  
  echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | \
    sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

  sudo apt update
  
  sudo apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

  # 5. Запустить Docker
  sudo systemctl start docker
  sudo systemctl enable docker

  # 6. Проверить
  sudo docker run hello-world

  # 7. Готово! Теперь можно запустить скрипт:
  cd /opt/remnanode
  ./setup-remnanode.sh

  ❓ ЕСЛИ ВСЁ ЕЩЁ НЕ РАБОТАЕТ
═══════════════════════════════════════════════════════════════════════════════

Проверьте статус Docker:
  sudo systemctl status docker.service

Посмотрите детальные логи:
  sudo journalctl -xeu docker.service | tail -30

Если видите ошибку про containerd, попробуйте перезагрузиться:
  sudo reboot

После перезагрузки:
  sudo systemctl start docker
  sudo docker run hello-world
