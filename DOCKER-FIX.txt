╔═══════════════════════════════════════════════════════════════════════════╗
║  ✅ РЕШЕНИЕ: "Unable to locate package docker-compose-plugin"             ║
╚═══════════════════════════════════════════════════════════════════════════╝

Вы получили ошибку:
  E: Unable to locate package docker-compose-plugin

Это означает, что docker-compose-plugin находится не в стандартном репозитории 
Ubuntu. Вот два быстрых решения:

╔═══════════════════════════════════════════════════════════════════════════╗
║  РЕШЕНИЕ 1️⃣ : Добавить официальный репозиторий Docker (5-10 минут)     ║
╚═══════════════════════════════════════════════════════════════════════════╝

Выполните команды по порядку:

  sudo apt update && sudo apt upgrade -y
  
  sudo apt install -y curl wget git nano jq ca-certificates gnupg lsb-release
  
  sudo mkdir -p /etc/apt/keyrings
  
  curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
    sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
  
  echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
    https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | \
    sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
  
  sudo apt update
  
  sudo apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
  
  sudo systemctl start docker && sudo systemctl enable docker

Проверьте:
  docker --version
  docker compose version

╔═══════════════════════════════════════════════════════════════════════════╗
║  РЕШЕНИЕ 2️⃣ : Быстрый способ - docker.io + standalone compose (2 мин)  ║
╚═══════════════════════════════════════════════════════════════════════════╝

Если Решение 1 кажется сложным, выполните:

  sudo apt update && sudo apt upgrade -y
  
  sudo apt install -y docker.io curl wget git nano jq
  
  sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" \
    -o /usr/local/bin/docker-compose
  
  sudo chmod +x /usr/local/bin/docker-compose
  
  echo "alias 'docker compose'='/usr/local/bin/docker-compose'" >> ~/.bashrc
  
  source ~/.bashrc
  
  sudo systemctl start docker && sudo systemctl enable docker

Проверьте:
  docker --version
  docker-compose --version

╔═══════════════════════════════════════════════════════════════════════════╗
║  🧪 ПРОВЕРКА (выполните эту команду, чтобы убедиться, что всё работает) ║
╚═══════════════════════════════════════════════════════════════════════════╝

  docker run hello-world

Должно вывести:
  Hello from Docker!
  This message shows that your installation appears to be working correctly.

Добавьте пользователя admin в группу docker (чтобы не писать sudo каждый раз):

  sudo usermod -aG docker admin

Выйдите и войдите заново, или:

  newgrp docker
