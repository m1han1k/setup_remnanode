  ШАГ 1: ПОДГОТОВКА СЕРВЕРА (выполните ОДИН РАЗ перед первым скриптом)
═══════════════════════════════════════════════════════════════════════════════

Выполните на сервере от root или sudo:

  sudo apt update && sudo apt upgrade -y

ВАЖНО: Установите Docker (ВЫБЕРИТЕ ВАРИАНТ):

  ⭐ ВАРИАНТ A (РЕКОМЕНДУЕТСЯ) - Официальный репозиторий Docker:
    sudo apt install -y curl wget git nano jq ca-certificates gnupg lsb-release
    sudo mkdir -p /etc/apt/keyrings
    curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
    echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
    sudo apt update
    sudo apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
    sudo systemctl start docker && sudo systemctl enable docker

  🔄 ВАРИАНТ B - Если Вариант A не сработал (docker.io + standalone compose):
    sudo apt install -y docker.io curl wget git nano jq
    sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
    sudo chmod +x /usr/local/bin/docker-compose
    echo "alias 'docker compose'='/usr/local/bin/docker-compose'" >> ~/.bashrc
    source ~/.bashrc
    sudo systemctl start docker && sudo systemctl enable docker

  Проверка:
    docker --version
    docker compose version
    docker run hello-world

  Если ошибка "docker compose not found":
    → Прочитайте DOCKER-INSTALL.md (полная инструкция обоих вариантов)

  Создать пользователя admin (если еще не создан):
    sudo useradd -m -s /bin/bash admin
    sudo usermod -aG docker admin

  (Опционально) Для удобства UFW без пароля sudo:
    sudo visudo
    # Добавить строку: admin ALL=(ALL) NOPASSWD: /usr/sbin/ufw

  ШАГ 2: КЛОНИРОВАНИЕ ПРОЕКТА

От пользователя admin:

  sudo mv /tmp/remnanode /opt/remnanode
  sudo chown -R admin:admin /opt/remnanode

═══════════════════════════════════════════════════════════════════════════════
  ШАГ 3: ЗАПУСК СКРИПТА АВТОМАТИЧЕСКОЙ НАСТРОЙКИ
═══════════════════════════════════════════════════════════════════════════════

От пользователя admin:

  cd /opt/remnanode
  chmod +x setup-remnanode.sh         # Выданы права на выполнение
  ./setup-remnanode.sh                # ГЛАВНЫЙ СКРИПТ

Скрипт интерактивно запросит:

  1️⃣  DOMAIN
      Пример: node1.example.com
      ⚠️  Должен указывать на IP этого сервера (проверьте DNS)
      Команда для проверки: nslookup node1.example.com

  2️⃣  EMAIL
      Пример: admin@example.com
      💌 На этот email придут уведомления от Let's Encrypt

  3️⃣  SECRET_KEY
      Получить: панель remnawave → Добавить ноду → скопировать SECRET_KEY
      📝 Длинная base64-строка (2000+ символов)

  4️⃣  NODE_PORT (опционально)
      По умолчанию: 8080
      Просто нажмите Enter для пропуска

═══════════════════════════════════════════════════════════════════════════════
  ШАГ 4: ПРОВЕРКА РЕЗУЛЬТАТА
═══════════════════════════════════════════════════════════════════════════════

Всё должно пройти автоматически! Скрипт:

  ✓ Создает .env файл с конфигурацией
  ✓ Настраивает UFW файрвол (порты 22, 80, 443, 8080)
  ✓ Получает SSL-сертификат от Let's Encrypt
  ✓ Запускает контейнер remnanode
  ✓ Настраивает автоматическое продление сертификата (Cron)

Проверить:

  # Статус контейнера
  docker compose ps
  # Должен показать: remnanode    Up X seconds

  # Логи
  docker compose logs -f remnanode
  # Должны быть успешные сообщения подключения

  # Сертификат
  ls -la letsencrypt/live/<ВАШ-ДОМЕН>/
  # Должны быть: cert.pem, privkey.key, chain.pem

  # UFW (если используется)
  sudo ufw status
  # Должны быть открыты: 22, 80, 443, 8080

═══════════════════════════════════════════════════════════════════════════════
  ШАГ 5: ПОДКЛЮЧЕНИЕ К ПАНЕЛИ REMNAWAVE
═══════════════════════════════════════════════════════════════════════════════

В панели remnawave:

  1. Перейти → Управление ноды → Добавить новую ноду
  2. Указать:
     - DOMAIN: <то же самое, что вводили в скрипт>
     - NODE_PORT: 8080 (или то, что выбрали)
     - SECRET_KEY: <то же самое, что вводили в скрипт>
  3. Проверить, что нода появилась с статусом "Online"
  4. Создать конфигурацию и проверить подключение клиента

Проблема: "DNS запись не указывает на сервер"
→ Проверьте: nslookup node1.example.com
→ Должен вернуть IP вашего сервера

Проблема: "Сертификат не получен"
→ Проверьте: sudo netstat -tlnp | grep :80
→ Порт 80 не должен быть занят другим приложением
→ Попробуйте вручную: ./scripts/issue-cert.sh

Проблема: "Контейнер не запускается"
→ Проверьте логи: docker compose logs remnanode
→ Если SECRET_KEY неверный:
   - Отредактируйте: nano .env
   - Перезапустите: docker compose restart remnanode

Проблема: "Требуется sudo для UFW"
→ Скрипт попросит пароль, вводите его
→ Или настройте sudo без пароля для admin пользователя
